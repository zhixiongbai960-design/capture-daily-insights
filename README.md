# Capture Daily Insights · 个人觉察档案

把零散的经历、想法和选择，变成有原话、有情绪、有来源、能持续回顾的个人认知资产。

它不只是帮你“记下来”，还帮助你逐步了解自己、看见观点的变化，并追踪想法有没有变成行动。需要时说一句“整理画像”，就能把问卷和记录整理为有证据的个人画像，并保留每次变化的完整版本。

- **做内容的人**：积累带真实语气和经历的素材，二创时不只剩下平淡的摘要。
- **创业者**：复盘选择、合作和行动结果，沉淀可复用的判断。
- **职场人**：建立自己的经验与决策参考库。
- **想了解自己的人**：通过问卷或对话，梳理热爱、擅长、价值观和人生关键事件。

## 一句话安装

复制整段，发送给支持 Skill 安装的 Agent：

```text
请帮我安装这个 Skill，安装后在当前工作目录中初始化我的个人觉察档案；如果已有档案，请沿用，不要覆盖。完成后告诉我保存位置，以及如何开始个人探索、日常记录和设置定期复盘：
https://github.com/zhixiongbai960-design/capture-daily-insights/tree/main/capture-daily-insights
```

不需要填写 subject_id，也不需要自己设计文件夹。

如果 Agent 不支持从链接安装，请下载本仓库中的整个 `capture-daily-insights/` 文件夹，按该 Agent 的 Skill 安装方式放置。不要只复制 SKILL.md。宿主需要有文件读写能力；定时任务是否可用取决于宿主。

## 安装后怎么用

### 1. 了解自己：两种方式任选，也可以混用

> 我想梳理自己的热爱、擅长和价值观，先把空白模板给我。

你会得到两份只有问题、没有答案的模板：

- [热爱、擅长与价值观](capture-daily-insights/assets/self-discovery.md)
- [人生关键事件](capture-daily-insights/assets/life-events.md)

自行填写后上传，Agent 保存原始回答。上传问卷不会自动生成画像；想总结时，再说“整理画像”即可。

也可以说：

> 用对话的方式带我梳理，每次问我一个问题。

支持跳题、暂停和从已保存的进度继续；不适用的人生阶段可以跳过，不必回答隐私问题。

### 2. 直接开始记录，不用先完成问卷

> 记一下：今天我意识到，真正让我不舒服的不是方案被拒绝，而是责任没有说清楚……

Agent 会整理背景与来源、原话、情绪与态度、核心观点、延伸思考及历史关联，并保存 Markdown 和更新索引。

也可以交给它朋友圈文字、会议转写、聊天片段或截图。多人材料会区分发言归属，不把别人的观点记到你身上。

> 我会分几次发，等我说发完再整理。

> 先讨论，暂时不要记录。

这些指令优先于自动记录。个人探索与日常记录可以同时进行。

### 3. 整理画像：只需说一句话

> 整理画像。

首次生成或以后更新，都用这句话。Agent 会结合人生关键事件、热爱、擅长与价值观资料，对照近半年的记录，维护两份画像：

- **基础画像**：现在是谁、想做什么、热爱与擅长什么、看重什么，以及适合如何协作。
- **成长路径与深层画像**：人生主线、观点与选择的变化，以及兴趣、才能和价值观之间的联系。

除了分别总结四个维度，还会回答：哪些兴趣与才能反复一起出现？哪些价值观驱动了这些选择？三者之间有没有能够描述“这个人”的共同模式？每个重要判断附来源，区分本人自述、行动验证和 Agent 的待验证分析，不把喜欢当成擅长，也不把一时情绪写成人格定论。

**每次实质更新，都会留下一份新的完整版本；历史画像不覆盖、不删除。**你可以从版本索引查看自己如何变化。不必手动编号，也不用重新填写全部问卷；材料不足时标记未知，不强行凑结论。没有实质变化就不重复建版。

详细规则见 [画像整理标准](capture-daily-insights/references/profile-curation.md)。已安装旧版的用户可把上面的安装指令发给 Agent，请它更新 Skill，并沿用已有档案、不覆盖个人资料。

### 4. 设置定期复盘

> 把月度、季度和年度复盘的定时任务创建提示词给我。

Agent 提供已带入你的实际档案路径的三段提示词。分别复制给支持定时任务的 Agent，由它确认时区和创建结果。

| 周期 | 默认执行时间 | 回顾内容 |
| --- | --- | --- |
| 月度 | 每月 1 日 09:00 | 上月认知变化、矛盾与行动进展 |
| 季度 | 1、4、7、10 月 1 日 09:00 | 上季度主题归拢与认知演化 |
| 年度 | 每年 1 月 1 日 09:00 | 上年关键事件、行动结果与长期变化 |

**安装 Skill 或生成提示词，不等于已经创建定时任务。**宿主不支持时可以手动说“帮我做上个月的复盘”。已有半年任务不会被自动取消或替换。

## 数据保存在什么地方

首次使用默认在当前工作目录下创建独立的档案，而不是写入 Skill 安装目录：

```text
个人觉察档案/
├── README.md
├── 00_个人探索/       # 空白问卷、后续回答和访谈进度
├── 01_个人画像/       # 两份当前画像；版本历史/ 保存完整快照与索引
├── 02_觉察记录/       # 独立记录、索引与附件
├── 03_复盘与行动/     # 行动台账、月度／季度／年度复盘
└── 99_使用说明/       # 复盘规则与可复制的任务提示词
```

普通 Markdown + 相对链接，可备份、用 Obsidian 打开，或交给其他有文件访问能力的 Agent 继续使用。旧档案沿用原目录和索引，不要求迁移；支持 README 声明的目录及旧版 insights 等命名。

## 记录原则

- 原始表达与整理结果分开；转写纠正另作说明。
- 原话金句必须来自原文；Agent 改写明确标注，不冒充你的原话。
- 情绪提取要有依据，区分明确表达与推测，不做人格诊断。
- 新认识不覆盖旧认识，补充时保留时间和变化过程。
- Agent 的建议不等于你的承诺；没记录进展不等于没行动。
- 历史关联使用真实链接和具体关联理由，不按关键词硬凑。
- 批量补录与当时产生的觉察分开统计，不制造虚假的频率和转化率。

## 对开发者与维护者

[Skill 入口](capture-daily-insights/SKILL.md) 按需路由到初始化、个人探索、画像整理与版本留存、记录、复盘和自动化提示词说明。两份问卷随包分发，没有任何用户答案。

可选脚本只依赖 Python 3.10+ 标准库：

```bash
python3 capture-daily-insights/scripts/init_archive.py --archive /path/to/personal-insight-archive
python3 capture-daily-insights/scripts/archive_check.py --archive /path/to/personal-insight-archive
```

初始化可重复执行，不覆盖已有文件；遇到旧库或自定义结构会停止并要求 Agent 读取适配，不自动迁移。没有 Python 时可由 Agent 按说明完成文件操作。

校验脚本检查索引编号、必填结构、日期、链接和导航可达性；它不能判断观点是否真实、情绪提取是否准确，这些仍需 Agent 和用户核对。

## 隐私

本仓库只发布方法、空白模板和脚本。你的个人档案应保存在本地或私有空间，**不要提交到这个公共仓库**。

家庭、客户、合同、金额、联系方式及未脱敏对话默认私密。二创和公开分享前检查来源、语境和匿名化；Skill 不自动上传或发布任何档案。
