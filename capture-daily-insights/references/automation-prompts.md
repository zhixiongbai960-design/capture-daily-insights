# 可复制的自动复盘任务提示词

入口：[Skill](../SKILL.md)。

只生成提示词，不执行定时任务。输出前把 {{ARCHIVE_PATH}} 替换成用户档案的真实绝对路径；不把占位符直接交给用户。用户未确认时区时保留“请先确认我的时区”这个要求，不猜测。初始化脚本会自动填入路径。
目标 Agent 无法访问此路径时须先请用户提供可访问位置，不假装读过档案。不要把提供提示词说成已创建任务。
