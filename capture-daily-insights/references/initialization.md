# 初始化

入口：[Skill](../SKILL.md)。

1. 检查目标工作目录是否已有档案。现有档案遵从原结构，只补用户需要的缺项，不覆盖 README、不迁移资料。
2. 没有档案时默认使用当前工作目录下“个人觉察档案”。无法确定可写工作目录时只问保存位置。无需询问身份标识、目录编号、技术参数；称呼可暂留空。
3. 若 Python 可用，运行 `python3 <skill>/scripts/init_archive.py --archive <目标目录>`。脚本生成内部 UUID、相对链接、问卷与说明；同目录重复执行只补缺，不覆盖。出现不认识的 README 时停止自动初始化，先读取人工适配。
4. 无 Python 时按下列结构用宿主的文件编辑工具创建，保留同样的不覆盖原则。README 声明 archive_type: personal-insight-archive、subject_id（内部生成）、insights_dir: 02_觉察记录、profile_dir: 01_个人画像、exploration_dir: 00_个人探索、reviews_dir: 03_复盘与行动、guides_dir: 99_使用说明。
5. 提供两份模板的实际文件链接及自动复盘提示词文件链接。询问用户想先探索自己还是直接记录，也允许两者同时进行。不要暗示已创建定时任务。
6. 用户要定时提示词时，读取任务提示词说明；提供三段已经替换实际路径、无需用户编辑的文本。时区未确认时让目标 Agent 确认，不猜测。

## 新档案结构

- README.md：档案声明、导航、个人探索、记录与“整理画像”的自然语言入口
- 00_个人探索/INDEX.md：链接两份模板；回答和访谈进度按使用需要再创建
- 00_个人探索/热爱擅长价值观_空白模板.md
- 00_个人探索/人生关键事件_空白模板.md
- 01_个人画像/INDEX.md：空索引，不填造画像
- 02_觉察记录/INDEX.md、附件/
- 03_复盘与行动/INDEX.md、行动追踪.md、月度复盘/、季度复盘/、年度复盘/
- 99_使用说明/INDEX.md、自动复盘任务提示词.md

模板来源：[热爱擅长价值观](../assets/self-discovery.md)、[人生关键事件](../assets/life-events.md)。
重复执行不重复生成身份和目录；有名冲突则停下来检查，而不是把另一个人资料写进来。
