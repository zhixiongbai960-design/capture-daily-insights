# Periodic review system

## Contents

1. Shared rules
2. Monthly contradiction and action review
3. Quarterly topic consolidation
4. Half-year behavior analysis

## 1. Shared rules

- Review one subject only.
- Use complete natural months, quarters, and half-years.
- Treat dated insight files and the index as primary evidence.
- Preserve original wording when comparing old and new records.
- Do not manufacture contradictions or psychological conclusions.
- Mark missing action evidence as `needs confirmation`; absence of a record is not proof of inaction.
- Keep private material inside the archive unless the user explicitly authorizes publication.

## 2. Monthly contradiction and action review

Read the target month's records, related historical records, current profile, action tracker, and previous monthly review.

Produce:

1. Count and topic distribution of new insights.
2. Credible belief changes, applicability changes, unfulfilled commitments, or genuine inconsistencies.
3. Action status updates.
4. The month's three to five most important insights.
5. Questions that require the subject's confirmation.

Use this contradiction format:

```markdown
### Contradiction or change: title

- Old record (YYYY-MM-DD, “Title”): faithful excerpt
- New record (YYYY-MM-DD, “Title”): faithful excerpt
- Type: cognitive update / context change / unfulfilled commitment / genuine inconsistency / added boundary / needs confirmation
- Possible reason: clearly label inference
- Confirmation question: include only when needed
```

Action states:

- `observing`
- `needs confirmation`
- `not started` only when the subject confirms it
- `implemented` with result evidence
- `abandoned` with reason

## 3. Quarterly topic consolidation

Cluster the quarter's records semantically. Create a topic collection only when multiple records reveal meaningful development.

Each collection contains:

1. Scope and inclusion rule.
2. Record list with dates, links, and one-sentence summaries.
3. Evolution timeline: start, deepening, turning point, current conclusion.
4. Reusable conclusions supported across records.
5. Unresolved questions and evidence gaps.
6. Observable next actions.

Treat the current conclusion as provisional as of the quarter end.

## 4. Half-year behavior analysis

Analyze:

- Record count and monthly distribution.
- Dense periods and known context.
- Repeated, rising, and fading topics.
- Insights with no later action or recurrence.
- Action status counts and reliable conversion rates when the sample supports them.
- Emotional states associated with insights and later action, while separating correlation from causation.

Report data limitations. Do not create precise percentages when older records lack structured action states.
